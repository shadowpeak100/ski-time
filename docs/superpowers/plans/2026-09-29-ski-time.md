# Ski Time Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Ski Time Pebble watch face. Skiers carve the time into a snowy slope, and each minute an avalanche wipes the slope and new skiers redraw it.

**Architecture:**
- **Pure C modules** (no `pebble.h`, host-tested with `make -C tests`) own all the math: geometry, glyphs, layout, skier paths and timing, the avalanche field, and the battery-saver window.
- **Pebble-only modules** own drawing: static scene, chalet, sprites, avalanche rendering, complications, settings and the animation driver.
- **Background:** the static background is rendered once into the framebuffer and snapshotted into a `uint8_t` buffer. Every frame starts by copying that buffer back.

**Tech Stack:**
- Pebble SDK 4.x (`pebble` tool v5), C99, SDK 3 app format
- PebbleKit JS with a custom HTML settings page (no Clay)
- Host tests with the system `cc`

**Spec:** `docs/superpowers/specs/2026-09-29-ski-time-design.md`

**Reference implementation:** `docs/prototypes/design-board.html` (JavaScript in the `<script>` block). Function names cited below (`buildBackground`, `buildForeground`, `drawSkier`, `drawAvalanche`, …) refer to that file. When porting, keep every constant exactly as written there unless this plan gives a different value.

**Sister projects to copy patterns from:**
- `../constellation`: settings, config page, weather, complications, battery saver
- `../analog-adapt`: trig shim for host tests, `MOCK_*` build defines

## Global Constraints

- **Target platforms:** exactly `["basalt", "emery"]`. There is no round-screen code.
- **Screen sizes:** basalt 144×168, emery 200×228. Scale factor `k = W/200`.
- **No libm on the watch:** no `math.h` in `src/c/`. Use `geom_sqrt`, `geom_sin`, `geom_cos` (Task 2) and the Pebble `sin_lookup`/`cos_lookup`/`atan2_lookup`.
- **Pure modules** (`geom`, `glyphs`, `layout`, `skier`, `avalanche`, `saver`) include only `<stdint.h>`, `<stdbool.h>`, `<stddef.h>` and `trig.h`. They never include `<pebble.h>` directly.
- **Palette:** only Pebble GColors named in the spec. Jackets: Red, ChromeYellow, BlueMoon, VividViolet, Orange, VividCerulean, Folly, JaegerGreen. Tracks: DarkGray.
- **Timings (ms):**
  - crack 550; flow 700–1650; fade 300
  - first skier 1450; stagger 200; pair 150; stop 300; exit gap 30
  - frame 40
- **Complication strip:** height `round(0.14H)`. Nothing but complication text is drawn there.
- **Commits:** every commit message ends with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Build output:** pipe `pebble build` output through `tail -40`.

## Review Focus

1. **Midnight and noon rollover** (23:59→00:00, and 12:59→1:00 in 12-hour mode without a leading zero). The number of hour digits changes between the old and new time. Old skiers must still ski out and new ones must draw. Pinned by the Task 4 test `test_skiers_digit_count_change`.
2. **Settings change mid-animation.** Changing the clock format or track style while an avalanche is running must not corrupt skier pools. Task 8 rebuilds both sets and restarts cleanly. Covered by the manual check in Task 9 step 6.
3. **Pool exhaustion** on the longest times (08:08 is the worst case: 1,694 px on emery). The pool must never overflow. `truncated` must stay false for every minute of the day. Pinned by the Task 4 test `test_skiers_all_minutes`.
4. **Avalanche drawing into the complication strip or sky.** Billows near the drift line or the ridge must never leave pixels outside the slope. Task 7 restores the pixels outside the slope from the background after the vector pass. Verified by the screenshot at `MOCK_ANIM_MS=1500`.
5. **Battery saver entered during an animation.** The animation must stop immediately and the face must show the new time at rest. Task 9 adds `anim_stop()` to `apply_saver`.

```c
// Floating-point stand-in for the firmware trig tables. Host only.
#include <math.h>
#include "trig_shim.h"

#define TWO_PI_D 6.28318530717958647692

int32_t sin_lookup(int32_t a) { return (int32_t)lround(sin((double)a * TWO_PI_D / TRIG_MAX_ANGLE) * TRIG_MAX_RATIO); }
int32_t cos_lookup(int32_t a) { return (int32_t)lround(cos((double)a * TWO_PI_D / TRIG_MAX_ANGLE) * TRIG_MAX_RATIO); }

// Matches PebbleOS: standard atan2(y, x) in [0, 2*pi), angle 0 on the +x axis.
int32_t atan2_lookup(int16_t y, int16_t x) {
  double a = atan2((double)y, (double)x);
  if (a < 0) a += TWO_PI_D;
  return (int32_t)(a * TRIG_MAX_ANGLE / TWO_PI_D) & (TRIG_MAX_ANGLE - 1);
}
```

```c
#ifndef GEOM_H
#define GEOM_H
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct { float x, y; } Vec2;
typedef Vec2 (*GeomMap)(float u, float v, const void *ctx);

#define GEOM_STEPS 60   // dense samples per cubic segment before arc-length resampling

float geom_sqrt(float v);
float geom_sin(float rad);
float geom_cos(float rad);
Vec2  geom_norm(float x, float y);

// Samples a cubic chain {x0,y0, c1x,c1y,c2x,c2y,x1,y1, ...} (n floats) through `map`,
// emitting points spaced `step` apart along the curve plus the exact end point. Returns count.
int geom_sample_chain(const float *chain, int n, GeomMap map, const void *ctx, float step, Vec2 *out, int max);

// Unit direction from p[i-w] to p[i+w], clamped to the array.
Vec2 geom_tangent(const Vec2 *p, int n, int i, int w);

// mulberry32, bit-identical to the prototype's `mulberry`, for deterministic scenery.
typedef struct { uint32_t a; } Mulberry;
float mulberry_next(Mulberry *m);

#endif
```

`src/c/geom.c`:
```c
#include "geom.h"
#include "trig.h"

float geom_sqrt(float v) {
  if (v <= 0) return 0;
  union { float f; uint32_t i; } u = { v };
  u.i = 0x1fbd1df5u + (u.i >> 1);
  float r = u.f;
  for (int i = 0; i < 4; i++) r = 0.5f * (r + v / r);
  return r;
}

static int32_t rad_to_angle(float rad) {
  return (int32_t)(rad * (TRIG_MAX_ANGLE / 6.28318531f)) & (TRIG_MAX_ANGLE - 1);
}
float geom_sin(float rad) { return (float)sin_lookup(rad_to_angle(rad)) / TRIG_MAX_RATIO; }
float geom_cos(float rad) { return (float)cos_lookup(rad_to_angle(rad)) / TRIG_MAX_RATIO; }

Vec2 geom_norm(float x, float y) {
  float l = geom_sqrt(x * x + y * y);
  if (l == 0) l = 1;
  return (Vec2){ x / l, y / l };
}

static float cubic1(float a, float b, float c, float d, float t) {
  float m = 1 - t;
  return m * m * m * a + 3 * m * m * t * b + 3 * m * t * t * c + t * t * t * d;
}

int geom_sample_chain(const float *ch, int n, GeomMap map, const void *ctx, float step, Vec2 *out, int max) {
  if (max < 1 || n < 8) return 0;
  int cnt = 0;
  Vec2 prev = map(ch[0], ch[1], ctx);
  out[cnt++] = prev;
  float need = step, x0 = ch[0], y0 = ch[1];
  for (int i = 2; i + 5 < n; i += 6) {
    for (int s = 1; s <= GEOM_STEPS; s++) {
      float t = (float)s / GEOM_STEPS;
      Vec2 cur = map(cubic1(x0, ch[i], ch[i + 2], ch[i + 4], t), cubic1(y0, ch[i + 1], ch[i + 3], ch[i + 5], t), ctx);
      float ax = prev.x, ay = prev.y, dx = cur.x - ax, dy = cur.y - ay;
      float seg = geom_sqrt(dx * dx + dy * dy);
      while (seg >= need) {
        float r = need / seg;
        ax += (cur.x - ax) * r; ay += (cur.y - ay) * r;
        if (cnt < max) out[cnt++] = (Vec2){ ax, ay };
        seg -= need; need = step;
      }
      need -= seg;
      prev = cur;
    }
    x0 = ch[i + 4]; y0 = ch[i + 5];
  }
  if (cnt < max) out[cnt++] = prev;
  return cnt;
}

Vec2 geom_tangent(const Vec2 *p, int n, int i, int w) {
  int a = i - w < 0 ? 0 : i - w, b = i + w > n - 1 ? n - 1 : i + w;
  return geom_norm(p[b].x - p[a].x, p[b].y - p[a].y);
}

float mulberry_next(Mulberry *m) {
  m->a += 0x6D2B79F5u;
  uint32_t a = m->a;
  uint32_t t = (a ^ (a >> 15)) * (a | 1u);
  t = (t + (t ^ (t >> 7)) * (t | 61u)) ^ t;
  return (float)(t ^ (t >> 14)) / 4294967296.0f;
}
```

```c
const Vec2 FALL = { -0.6f, 0.8f };
const Vec2 ACROSS = { 0.8f, 0.6f };

// Math.round for the positive values used here.
static int16_t rnd(float v) { return (int16_t)(v >= 0 ? v + 0.5f : v - 0.5f); }

float layout_ridge_y(const Layout *L, float x) {
  float f = x / L->W;
  float fc = f < 0 ? 0 : f > 1 ? 1 : f;
  return L->y_l + (L->y_r - L->y_l) * f - geom_sin(3.14159265f * fc) * L->bulge;
}

float layout_berm_y(const Layout *L, float x) {
  return L->comp_top - 1 + geom_sin(x * 0.07f) * 1.2f * L->k;
}

Vec2 layout_glyph_point(const Layout *L, uint8_t slot, float u, float v) {
  Pt16 b = L->boxes[slot];
  return (Vec2){ b.x + (u + (1 - v) * GLYPH_SLANT - GLYPH_SLANT / 2) * L->gw, b.y + v * L->gh };
}

void layout_init(Layout *L, int W, int H) {
  L->W = W; L->H = H;
  float k = L->k = W / 200.0f;
  L->comp_h = rnd(H * 0.14f);
  L->comp_top = H - L->comp_h;

  L->gw = rnd(W * 0.21f); L->gh = rnd(L->gw * 1.2f);
```

```c
    Vec2 q = cub(sk->ex, (float)i / SKI_EXIT_SEGS);
    float dx = q.x - prev.x, dy = q.y - prev.y;
    sk->ex_len[i] = sk->ex_len[i - 1] + geom_sqrt(dx * dx + dy * dy);
    prev = q;
  }
}

static bool build_one(SkierSet *set, const Layout *L, Skier *sk, GlyphStroke g, uint8_t slot, uint16_t t0, uint8_t color) {
  static Vec2 st[SKI_SCRATCH];
  const float k = L->k;
  BoxCtx bc = { L, slot };
  int ns = geom_sample_chain(g.pts, g.n, box_map, &bc, 1.0f, st, SKI_SCRATCH);
  if (ns < 2) return false;
  Vec2 start = st[0], d0 = geom_tangent(st, ns, 0, 3);
  Vec2 P0 = { L->W + 10.0f, clampf(start.y - (L->W + 10 - start.x) * 0.45f, layout_ridge_y(L, L->W) + 8 * k, L->comp_top - 10.0f) };
  float dx = start.x - P0.x, dy = start.y - P0.y, len = geom_sqrt(dx * dx + dy * dy);
  Vec2 a = geom_norm(-1, 0.45f);
  const float entry[8] = { P0.x, P0.y, P0.x + a.x * len * 0.35f, P0.y + a.y * len * 0.35f,
                           start.x - d0.x * len * 0.4f, start.y - d0.y * len * 0.4f, start.x, start.y };
  int ne = geom_sample_chain(entry, 8, id_map, NULL, 1.0f, st + ns, SKI_SCRATCH - ns);

  SkPt *p = set->pool + set->pool_used;
  int cap = set->pool_cap - set->pool_used, n = 0;
  for (int i = 0; i < ne - 1 && n < cap; i++) p[n++] = (SkPt){ q4(st[ns + i].x), q4(st[ns + i].y), 0 };
  uint16_t s_idx = (uint16_t)n;
  for (int i = 0; i < ns && n < cap; i++) p[n++] = (SkPt){ q4(st[i].x), q4(st[i].y), 0 };
  if (n < ne - 1 + ns) set->truncated = true;
  if (n <= s_idx + 1) return false;

  float t = t0;
  p[0].t = t0;
  for (int i = 1; i < n; i++) {
    Vec2 a0 = pv(&p[i - 1]), a1 = pv(&p[i]);
    float ddx = a1.x - a0.x, ddy = a1.y - a0.y, ds = geom_sqrt(ddx * ddx + ddy * ddy);
    Vec2 tg = tangent_pts(p, n, i, 2);
    float down = tg.x * FALL.x + tg.y * FALL.y;
    float v = 78 * k * (0.72f + 0.55f * (down > 0 ? down : 0)) * (1 - 0.35f * (tg.y < 0 ? -tg.y : 0));
    if (i < s_idx) {
      float e = smoothf(clampf((s_idx - i) / (30 * k), 0, 1));
      v = v + (170 * k - v) * e;
    }
    t += ds / v * 1000;
    p[i].t = (uint16_t)(t + 0.5f);
  }

  sk->pts = p; sk->n = (uint16_t)n; sk->s_idx = s_idx; sk->t0 = t0; sk->t_end = p[n - 1].t; sk->color = color;
  sk->end = pv(&p[n - 1]);
  sk->d_end = tangent_pts(p, n, n - 1, 3);
  sk->end_h = angle_of(sk->d_end);
  Vec2 rd = (sk->d_end.x * s_rest.x + sk->d_end.y * s_rest.y) >= 0 ? s_rest : (Vec2){ -s_rest.x, -s_rest.y };
  sk->rest_h = sk->end_h + (int16_t)(angle_of(rd) - sk->end_h);
  sk->stop_len = 4 * k;
  sk->rest_pos = (Vec2){ sk->end.x + sk->d_end.x * sk->stop_len, sk->end.y + sk->d_end.y * sk->stop_len };
  build_exit(sk, L);
  set->pool_used += (uint16_t)n;
  return true;
}

void skiers_init(SkierSet *set, SkPt *pool, uint16_t cap) {
  set->pool = pool; set->pool_cap = cap; set->pool_used = 0; set->count = 0; set->truncated = false;
  if (s_rest.x == 0) s_rest = geom_norm(0.92f, 0.39f);
}

void skiers_build(SkierSet *set, const Layout *L, const DigitSlot *slots, uint8_t nslots) {
  set->count = 0; set->pool_used = 0; set->truncated = false;
  for (uint8_t i = 0; i < nslots; i++) {
    uint8_t d = slots[i].digit, slot = slots[i].slot;
    for (uint8_t j = 0; j < glyph_stroke_count(d) && set->count < SKI_MAX; j++) {
      uint16_t t0 = SKI_DRAW_START_MS + slot * SKI_STAGGER_MS + j * SKI_PAIR_MS;
      if (build_one(set, L, &set->sk[set->count], glyph_stroke(d, j), slot, t0, (uint8_t)((slot * 2 + j) % 8)))

    }
  }
}

int32_t skier_pt_heading(const Skier *s, uint16_t i) {
  int a = i < 2 ? 0 : i - 2, b = i + 2 > s->n - 1 ? s->n - 1 : i + 2;
  return atan2_lookup(s->pts[b].y - s->pts[a].y, s->pts[b].x - s->pts[a].x);
}

SkierState skier_state(const Skier *s, uint16_t t) {
  SkierState r = { 0 };
  if (s->n < 2 || t < s->t0) return r;
  r.visible = true;
  if (t <= s->t_end) {
    int lo = 0, hi = s->n - 1;
    while (hi - lo > 1) { int m = (lo + hi) / 2; if (s->pts[m].t <= t) lo = m; else hi = m; }
    const SkPt *a = &s->pts[lo], *b = &s->pts[hi];
    int32_t span = b->t - a->t, f = span > 0 ? (((int32_t)(t - a->t)) << 8) / span : 0;
    r.x = (int16_t)(a->x + (((b->x - a->x) * f) >> 8));
    r.y = (int16_t)(a->y + (((b->y - a->y) * f) >> 8));
    int32_t h0 = skier_pt_heading(s, lo), h1 = skier_pt_heading(s, hi);
    r.h = h0 + ((((int16_t)(h1 - h0)) * f) >> 8);
    r.idx = (uint16_t)lo;
    return r;
  }
  float u = (t - s->t_end) / (float)SKI_STOP_MS;
  if (u > 1) u = 1;
  float e = 1 - (1 - u) * (1 - u), d = s->stop_len * e;
  r.x = q4(s->end.x + s->d_end.x * d);
  r.y = q4(s->end.y + s->d_end.y * d);
  r.h = s->end_h + (int32_t)((s->rest_h - s->end_h) * smoothf(u));
  r.idx = s->n - 1;
  r.spray = u < 1 ? (uint8_t)(1 + u * 254) : 0;
  return r;
}

SkierState skier_exit_state(const Skier *s, uint8_t order, uint16_t t, float k) {
  SkierState r = { .visible = true, .idx = s->n - 1 };
  int32_t te_ms = (int32_t)t - order * SKI_EXIT_GAP_MS;
  if (te_ms <= 0) { r.x = q4(s->rest_pos.x); r.y = q4(s->rest_pos.y); r.h = s->rest_h; return r; }
  float te = te_ms / 1000.0f, dist = 0.5f * 380 * k * te * te + 20 * k * te;
  if (dist >= s->ex_len[SKI_EXIT_SEGS]) { r.visible = false; return r; }
  int i = 0;
  while (s->ex_len[i + 1] < dist) i++;
  float f = (dist - s->ex_len[i]) / (s->ex_len[i + 1] - s->ex_len[i]);
  float tt = (i + f) / SKI_EXIT_SEGS;
  Vec2 q = cub(s->ex, tt), dv = cub_d(s->ex, tt);
  Vec2 du = geom_norm(dv.x, dv.y);
  int32_t hp = s->rest_h + (int16_t)(angle_of(du) - s->rest_h);
  float w = smoothf(clampf(te / 0.35f, 0, 1));
  r.x = q4(q.x); r.y = q4(q.y);
  r.h = s->rest_h + (int32_t)((hp - s->rest_h) * w);
  return r;
}

uint16_t skiers_duration(const SkierSet *set) {
  uint16_t m = 0;
  for (uint8_t i = 0; i < set->count; i++) if (set->sk[i].t_end > m) m = set->sk[i].t_end;
  return m + SKI_STOP_MS + 300;
}
```

```c
#include "avalanche.h"
#include "trig.h"

// Integer maths throughout the per-pixel path: u5 = 5u = 4y - 3x, s = (4x + 3y) / 5.
static const uint8_t BAYER[16] = { 0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5 };
uint8_t aval_bayer(int x, int y) { return BAYER[((y & 3) << 2) | (x & 3)]; }
static bool dith(int x, int y, int32_t p256) { return (int32_t)aval_bayer(x, y) * 16 + 8 < p256; }

float aval_noise(float x) {
  float v = 0.5f + 0.3f * geom_sin(x) + 0.2f * geom_sin(x * 2.3f + 1.7f);
  return v < 0 ? 0 : v > 1 ? 1 : v;
}

void aval_streaks(uint8_t st[AV_MAX_S]) {
  for (int s = 0; s < AV_MAX_S; s++) {
    float v = 0.5f + 0.5f * geom_sin(s * 0.55f + 3 * aval_noise(s * 0.1f));
    float p = v * v; p *= p; p *= p;
    st[s] = (uint8_t)(p * 255);
  }
}

void aval_frame(AvalFrame *A, const Layout *L, uint16_t t) {
  A->active = t >= AV_FLOW_START_MS && t <= AV_FLOW_END_MS + AV_FADE_MS;
  if (!A->active) return;
  float k = L->k, a = (t - AV_FLOW_START_MS) / (float)(AV_FLOW_END_MS - AV_FLOW_START_MS);
  if (a > 1) a = 1;
  float p = a * geom_sqrt(geom_sqrt(a));                               // a^1.25
  A->a = a;
  A->uf = L->u0 + (L->u1 - L->u0) * p;
  A->fade = t > AV_FLOW_END_MS ? 1 - (t - AV_FLOW_END_MS) / (float)AV_FADE_MS : 1;
  A->grow = (a * 5 < 1 ? a * 5 : 1) * A->fade;
  float amp = a * 2.5f < 1 ? a * 2.5f : 1, tau = t / 1000.0f;
  for (int s = 0; s < AV_MAX_S; s++) {
    float f = A->uf + amp * k * (14 * (aval_noise(s * 0.045f + 1.3f) - 0.5f) + 6 * (aval_noise(s * 0.13f + tau * 1.7f) - 0.5f));
    A->front5[s] = (int16_t)(f * 5);
  }
  A->body5 = (int16_t)((26 * k * A->grow + 1) * 5);
}

float aval_front(const AvalFrame *A, float s) {
  int i = (int)(s + 0.5f);
  if (i < 0) i = 0;
  if (i >= AV_MAX_S) i = AV_MAX_S - 1;
  return A->front5[i] / 5.0f;
}

// Churned-snow texture, Q8 (0..255). Integer port of the prototype's n2(0.3s, 0.3u - 9tau).
static int32_t churn(int32_t s, int32_t u5, int32_t t) {
  int32_t a1 = s * 4068 + 20861 * sin_lookup((438 * u5 - 66 * t) & 0xFFFF) / TRIG_MAX_RATIO;
  int32_t a2 = 688 * u5 - 103 * t + 15646 * cos_lookup((2816 * s) & 0xFFFF) / TRIG_MAX_RATIO;
  int32_t c = 128 + 72 * sin_lookup(a1 & 0xFFFF) / TRIG_MAX_RATIO + 56 * sin_lookup(a2 & 0xFFFF) / TRIG_MAX_RATIO;
  return c < 0 ? 0 : c > 255 ? 255 : c;
}

AvPix aval_pixel(const AvalFrame *A, const uint8_t *streak, float k, int x, int y, uint16_t t) {
  int32_t u5 = 4 * y - 3 * x, s = (4 * x + 3 * y) / 5;
  if (s < 0) s = 0;
  if (s >= AV_MAX_S) s = AV_MAX_S - 1;
  int32_t dep = A->front5[s] - u5;
  int32_t sh0 = (int32_t)(-45 * k), sh1 = (int32_t)(-10 * k);
  if (dep < sh0) return AV_NONE;
  if (dep < 0) {
    if (dep < sh1) {
      int32_t p = 128 * (dep - sh0) / (sh1 - sh0) * (int32_t)(A->grow * 256) / 256;
      if (dith(x, y, p)) return AV_SHADOW;
    }
    return AV_NONE;
  }
  int32_t body = A->body5;
  if (dep < body) {
    int32_t t256 = dep * 256 / body, c = churn(s, u5, t);
    if (c > 220 && t256 < 154) return AV_BLUE;
    int32_t p = (c - 102) * 461 / 256 * (256 - t256) / 256;
    return dith(x, y, p) ? AV_CELESTE : AV_WHITE;
  }
  int32_t wake = (int32_t)(200 * k);
  if (dep < body + wake) {
    int32_t w256 = (256 - (dep - body) * 256 / wake) * (int32_t)(A->fade * 256) / 256;
    int32_t p = streak[s] * w256 / 256 * 205 / 256;
    if (dith(x, y, p)) return AV_CELESTE;
  }
  return AV_RESTORE;
}
```
