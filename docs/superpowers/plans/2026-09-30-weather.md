# Ski Time Phase 3 (Weather and Animation Modes) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ski Time shows the current weather in its sky on Emery: clouds, overcast, fog, drizzle, rain, snow and thunderstorms, all tinted by the time of day. A three-level Animations setting (Full, Balanced, Battery saver) and the battery-saver schedule control how much it moves.

**Architecture:**
- **Pure, host-tested modules:**
  - `weather`: WMO mapping, layer definitions, colour tables, palette budget, precipitation geometry
  - `bolt`: fixed lightning bolt geometry
  - `saver`: effective animation mode
- **Watch modules:**
  - `scene`: bakes clouds, the deck and fog into the stored background during the existing rebuild
  - `wx_draw`: rain, snow, the bolt and the flash, drawn per frame (Emery only)
  - `main.c`: tracks the weather, applies it at the minute change with the time of day, picks the effective mode, and runs a 100 ms rest timer only for Full animations with moving weather

**Tech Stack:** C99 Pebble SDK 3 (pebble tool v5), PebbleKit JS, host tests with `cc`.

**Spec:** `docs/superpowers/specs/2026-09-30-weather-design.md`. The reference prototypes are `docs/prototypes/weather.html` and `docs/prototypes/battery-modes.html`.

## Global Constraints

- **Platforms:** weather rendering (background layers and per-frame weather) is Emery only, behind `#ifdef PBL_PLATFORM_EMERY`. Basalt gets only the settings fields and the effective-mode logic. The basalt heap at rest must stay at least 3232 B.
- **Pure modules** include only `<stdint.h>`, `<stdbool.h>`, `<stddef.h>`, `trig.h`, `geom.h`, `layout.h`, `daypart.h` and `theme.h`. They never include `pebble.h` or `math.h`.
- **Colours** use `C8(0xRRGGBB)` Col8 values, converted to GColor with `(GColor){ .argb = c }`.
- **Background budget:** at most 16 colours for every phase × weather combination. The background is drawn without antialiasing.
- **Weather timing:** a new weather applies at the next minute change, through the same background rebuild as the time of day. It applies immediately in Battery saver mode, when settings change, and at launch.
- **Keep clear of the strip:** precipitation is never drawn at or below `comp_top - 2`.
- **Commits:** every message ends with a blank line and exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Pipe `pebble build` through `tail -40`.
- **Emulator:** if it fails in the command sandbox, retry with the sandbox disabled. If it hangs, run `pebble kill` and `pebble wipe`, then reinstall. Wipe before MOCK builds. Kill any `pebble logs` you start.

```c
WxKind wx_from_wmo(int c) {
  if (c == 0) return WX_CLEAR;
  if (c == 1 || c == 2) return WX_PARTLY;
  if (c == 3) return WX_OVERCAST;
  if (c == 45 || c == 48) return WX_FOG;
  if (c >= 51 && c <= 57) return WX_DRIZZLE;
  if ((c >= 61 && c <= 67) || (c >= 80 && c <= 82)) return WX_RAIN;
  if ((c >= 71 && c <= 77) || c == 85 || c == 86) return WX_SNOW;
  if (c >= 95 && c <= 99) return WX_STORM;

uint8_t wx_sky(Daypart d, WxKind w, Col8 out[4]) {
  const WxDef *df = wx_def(w);
  if (df->sky == WXSKY_CLEAR) { const Theme *t = theme_for(d); for (uint8_t i = 0; i < t->nsky; i++) out[i] = t->sky[i]; return t->nsky; }
  const Col8 *src = df->sky == WXSKY_STORM ? STM[d] : OVC[d];
  for (uint8_t i = 0; i < SKY_N[d]; i++) out[i] = src[i];
  return SKY_N[d];
}

uint8_t wx_bg_palette(Daypart d, WxKind w, Col8 out[32]) {
  const Theme *t = theme_for(d); const WxDef *df = wx_def(w); uint8_t n = 0; Col8 s[4];
  uint8_t ns = wx_sky(d, w, s);
  for (uint8_t i = 0; i < ns; i++) add(out, &n, s[i]);
  if (!df->deck) {
    if (t->body.kind == BODY_SUN) { add(out, &n, t->body.core); add(out, &n, t->body.glow); }
    else { add(out, &n, C8(0xFFFFFF)); add(out, &n, C8(0xAAAAAA)); add(out, &n, C8(0x000055)); }
    if (t->stars) { add(out, &n, C8(0xFFFFFF)); add(out, &n, C8(0xAAFFFF)); add(out, &n, C8(0xFFFFAA)); add(out, &n, C8(0x5555AA)); }

  if (df->fog256) add(out, &n, FOG[d]);
  for (int i = 0; i < 4; i++) { add(out, &n, t->far[i]); add(out, &n, t->near_[i]); }

  return n;
}
```

```c
static uint32_t mix(uint32_t x) { x ^= x >> 16; x *= 0x7feb352dU; x ^= x >> 15; x *= 0x846ca68bU; x ^= x >> 16; return x; }
static float hsh(int i, uint32_t salt) { return (mix((uint32_t)i * 0x9E3779B9u ^ salt) >> 8) / 16777216.0f; }
static float fmodp(float a, float m) { float q = (float)(int)(a / m); float r = a - q * m; return r < 0 ? r + m : r; }

int wx_drop_count(const WxDef *d, bool still) {
  if (d->precip == PRECIP_RAIN) return still ? (d->len < 3 ? d->rate * 2 : d->rate * 17 / 10) : d->rate;
  if (d->precip == PRECIP_SNOW) return still ? d->rate * 3 / 2 : d->rate;
  return 0;
}
bool wx_rain_drop(const Layout *L, const WxDef *d, int i, float t, bool still, int8_t wind, Vec2 *a, Vec2 *b) {
  if (still) t = 2.3f;
  const float k = L->k, top = L->comp_top - 2, span = top + 20, slant = 0.3f * wind, len = d->len * k;
  const float x0 = hsh(i, 0xA1u) * (L->W + 40) - (wind > 0 ? 40 : wind == 0 ? 20 : 0);
  const float y = fmodp(hsh(i, 0xB7u) * span + t * d->speed * k, span) - 10;
  if (y + len > top) return false;
  const float x = x0 + (y + 10) * slant;
  *a = (Vec2){ x, y }; *b = (Vec2){ x + len * slant, y + len };
  return true;
}
bool wx_flake(const Layout *L, const WxDef *d, int i, float t, bool still, int8_t wind, int16_t *x, int16_t *y, bool *big) {
  if (still) t = 2.3f;
  const float k = L->k, top = L->comp_top - 2;
  const float sp = d->speed * k * (0.6f + hsh(i, 0xD4u) * 0.8f);
  const float yy = fmodp(hsh(i, 0xC3u) * top + t * sp, top);
  if (yy > top - 3) return false;
  const float xx = fmodp(hsh(i, 0xB2u) * L->W + geom_sin(t * 1.3f + i) * 3 * k + 0.3f * wind * yy, (float)L->W);
  *x = (int16_t)xx; *y = (int16_t)yy; *big = (i % 3) == 0;
  return true;
}
```
